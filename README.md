# Lobotomy Modern Engine (LME) v0.7.2

**Lobotomy Corporation** の長時間プレイ時のメモリリーク（クラッシュ）・後半日数のフレームレート低下・バニラ固有の9大バグ・UIの文字切れ／文字縮小問題をまとめて解決する統合エンジン改善MODです。

---

## 📦 配布パッケージの選び方（あり版 / なし版）

GitHub の **Releases**（または `dist/` フォルダ）にて、用途に合わせて **2つのエディション（あり版 / なし版）** を用意しています。

| パッケージ名 | デバッグ・育成緩和機能<br>（1LOB強化・初期装備無双） | おすすめの対象者 |
| :--- | :---: | :--- |
| **なし版（Standard Edition）**<br>`LobotomyModernEngine_v0.7.2_Standard_*.zip` | **OFF（無効）** | **【通常のプレイヤー向け】**<br>バニラのゲームバランスを一切崩さず、**軽量化・メモリリーク修正・バニラ9大バグ修正・UI文字サイズ改善のみ** を適用したい方 |
| **あり版（DebugPlus Edition）**<br>`LobotomyModernEngine_v0.7.2_DebugPlus_*.zip` | **ON（有効）** | **【周回・検証・時短プレイ向け】**<br>上記すべての改善に加え、**「職員ステータス強化コスト一律 1 LOB」「初期装備（警棒・スーツ）＆懺悔E.G.Oの1撃鎮圧・無敵化」** が最初から有効になっている版 |

> 💡 **補足**: 「なし版（Standard）」と「あり版（DebugPlus）」の中身のプログラムは共通であり、ゲーム中に **`F8` キー**（または **`F9` 診断画面**、もしくは `BepInEx/config/com.isaka.lobotonymodernengine.cfg`）からいつでも個別に ON / OFF を切り替えられます。

さらに各エディションには、環境に合わせて以下の2種類があります：
- **`_FullBepInEx.zip`（BepInEx本体同梱フルセット）**: バニラ環境にそのまま解凍するだけで導入完了する初心者向けフルパック。
- **`_PluginOnly.zip`（プラグイン単体版）**: すでに BepInEx 5.x を導入済みの方向け（`BepInEx/plugins/` と `config/` のみ）。

## 🚀 導入方法

### A. フルセット版（`_FullBepInEx.zip`）を使う場合
1. Steam のライブラリで『Lobotomy Corporation』を右クリック → **「管理」＞「ローカルファイルを閲覧」** を開きます。
2. `LobotomyCorp.exe` があるフォルダに、ZIPの中身（`BepInEx` フォルダ、`winhttp.dll`、`doorstop_config.ini`）をすべてドラッグ＆ドロップして上書き展開します。
3. ゲームを起動すると自動適用されます（ゲーム内で **`F9` キー** を押すと稼働モニターが開きます）。

### B. プラグイン単体版（`_PluginOnly.zip`）を使う場合
1. 導入済みの `BepInEx` フォルダに ZIP 内の `BepInEx` フォルダを上書きコピーしてください。

### アンインストール方法
- `BepInEx/plugins/LobotomyModernEngine.dll` を削除（フルセット導入時は `winhttp.dll` を削除）するだけで、いつでも完全に元のバニラ状態に戻ります。

## 🔧 仕組み解説（なぜ軽くなり、どうやってバグを直しているのか）

Lobotomy Corporation は Unity 2017.4（Mono .NET 3.5相当）で動作しており、後半日数や長時間プレイで極端に重くなる主因は「グラフィック性能不足」ではなく **「毎フレームの不要なオブジェクト再生成（GCスパイク）とテクスチャ／マテリアルのメモリリーク」** にあります。
本MODはゲーム本体のファイルを書き換えず、起動時にメモリ上でメソッドを差し替える（Harmonyパッチ）ことで以下の4つのレイヤーを改善しています。

### 1. メモリリーク根絶・CPU負荷軽減の仕組み

1. **Spineアトラス＆テクスチャの再利用キャッシュ (`SpineAtlasCachePatch`)**
   - **バニラの問題**: 職員や幻想体のアニメーション切替時に毎回 `Texture2D` や `Material` が新規生成され、古いオブジェクトがアンロードされずにVRAM/RAMへ永久に蓄積します（数時間で数GB膨れ上がりクラッシュする最大の原因）。
   - **本MODの仕組み**: 生成されたアトラス・マテリアルを辞書キャッシュ（WeakReferenceによる世代管理付き）に保持し、同一素材の再生成を遮断してメモリ増加を止めます。
2. **弾丸・照準カーソルのテクスチャ生成リーク防止 (`CursorLeakPatch`)**
   - **バニラの問題**: 弾丸照準の拡縮アニメーションのたびに毎フレーム `ScaleTexture` で新規 `Texture2D` を生成してリークしていました。
   - **本MODの仕組み**: スケール倍率を量子化してキャッシュし、毎フレームのテクスチャ生成アロケーションをゼロにしています。
3. **UI・ポートレート・収容室の「Dirtyフラグ（差分更新）」化 (`WorkerPortraitPatch`, `IsolateRoomPatch`, `SefiraPanelPatch`)**
   - **バニラの問題**: 職員の顔グラフィック（`WorkerPortraitSetter.LateUpdate`）、収容室（`IsolateRoom.Update` / `CheckQliphothCounter`）、部門パネルが、**数値や色が1ミリも変わっていなくても毎フレーム全パーツ再構築・文字列生成（`ToString()`）と Canvas メッシュ再計算** を走らせていました。
   - **本MODの仕組み**: 前回フレームの状態（クリフォトカウンター値、ルームカラー、装備・顔データ）を記憶し、変化がないフレームは更新ループ自体をスキップします。
4. **リスト取得のゼロアロケーション化＆カメラ判定共有 (`WorkerListCachePatch`, `SpineOptimizerPatch`)**
   - **バニラの問題**: 毎フレーム何百回も呼ばれる `GetAgentList()` 等が毎回 `new List<T>()` を複製し、さらに全ユニットが個別に `Camera.main`（内部でタグ検索）を呼び出していました。
   - **本MODの仕組み**: リスト変更時のみ更新される `ReadOnlyCollection` キャッシュを返し、カメラ座標も1フレームに1度だけスナップショットを取得して全ユニットで共有します。
5. **イベント通知 (`Notice.Send`) の Copy-on-Write 化 ＆ `TakeDamage` Transpiler 最適化**
   - イベント配信時のリスト複製を書き込み発生時のみ（Copy-on-Write）に限定し、ダメージ処理でバリア（シールド）が0枚のときは配列アロケーション自体をバイパスする IL Transpiler 最適化を施しています。

### 2. バニラ固有の9大バグ修正（個別ON/OFF対応）

バニラのコード記述ミスによって発生していた以下の9つのバグを、本来の仕様通りに動作するよう修正しています（すべて `.cfg` で1項目ずつ個別にON/OFF可能）。

| # | 通称 / 設定キー | バニラのバグ原因 | 本MODでの修正内容 |
| :--- | :--- | :--- | :--- |
| 1 | **いつでもどこでも黄昏バグ**<br>`FixTwilightArmorGlobalBuff` | `BossBirdArmor.GetDamageFactor()` が攻撃時、装備している武器が黄昏武器かチェックせず、黄昏防具を着ていれば**全武器の攻撃力が最大2倍**になっていた（さらに `UnitModel` 側で weapon と armor の null チェック対象を取り違えていた）。 | 武器・防具の null チェックを正し、黄昏武器（ID:200038）での攻撃時のみ防具のダメージ倍率ボーナスが乗るよう修正。 |
| 2 | **プラシーボ効果バグ（ケセド研究）**<br>`FixChesedBulletRefiningResearch` | ケセド部門の弾丸研究「HP、SP弾精製（ID:803）」を取得しても、回復量判定側が存在しない文字列キー `"upgrade_bullet"` を参照しており、回復量が25→40に増えていなかった。 | 研究ID `803` の取得状態を正しく判定し、HP/SP弾の回復量が40になるよう修正。 |
| 3 | **マルクトあげませんバグ**<br>`FixMalkuthBossMovementReward` | マルクトのコア抑制クリア報酬「職員の移動速度が増加」に対応する処理が `AgentModel.GetMovementBufBySefiraAbility()` に実装し忘れられていた。 | マルクトコア抑制クリア時に移動速度ボーナス（+10）が正しく加算されるよう修正。 |
| 4 | **溶ける愛ヤンデレ・ツンデレバグ**<br>`FixSlimeGirlBugs` | ①洞察作業が「普通/悪い」で終わった際、感染職員の変異処理の対象が作業者ではなく最新の感染者になっていた。<br>②感染者が50%を超えた際のカウンター減少判定の分母が「収容部門の生存職員数」ではなく「施設全体の生存職員数」になっていた。 | ①洞察失敗時に作業者自身が正しく変異するよう修正。<br>②収容部門内の生存職員数を分母として50%判定を行うよう修正。 |
| 5 | **壁に向かう女武器「叫び」バグ**<br>`FixLadyLookingAtWallWeapon` | 説明文は「勇気/慎重がランク3未満の場合、50%の確率でSP5減少」だが、コードが `勇気<3 && 慎重<3` かつ **確率100%で 0.1 ダメージ** になっていた。 | 説明文通り `勇気<3 \|\| 慎重<3` のとき **50%の確率で精神力に5ダメージ** 入るよう修正。 |
| 6 | **笑顔（団子）特殊キルバフ不発バグ**<br>`FixDangoWeaponKillBuff` | 特殊攻撃（6連撃）の1撃目で敵が死なないと即座に `skillAvailable = false` にされ、2〜6撃目でトドメを刺してもキルバフ（体力+3・正義+3）が一生入らなかった。 | 各ヒット直前の生存状態を追跡し、6連撃のどのヒットで倒しても確実にキルバフが付与されるよう修正。 |

### 3. UI・テキスト視認性修正の仕組み

- **ローディング画面の文字切れ修正（「システム初期化」が3文字で切れる問題）**:
  - `ContinueLoadingScene` 等のテキスト枠（`RectTransform`）が狭く、自動改行された2行目が `VerticalWrapMode.Truncate` で切り捨てられていたため、該当テキストの横幅拡張と `Overflow` 解放を行い全文字を表示します。
- **エンサイクロペディア（図鑑）・ギフト欄の文字サイズ改善**:
  - アブノーマリティ記録（`CreatureInfoWindow.SetDesc`）を 20pt の読みやすいサイズに固定し、`Canvas.ForceUpdateCanvases()` で正確な高さを算出してから再配置することで段落重なりを防ぎます。
  - ギフト説明欄（`GiftSlot` / `AgentGiftSlot`）で Unity の `BestFit` による極小化（10ptの豆粒文字化）を解除し、15〜16ptでくっきり読めるようにしています。

### 4. デバッグ・育成緩和機能（「あり版 / DebugPlus」または設定ON時）

- **職員強化コスト一律 1 LOB 化 (`CheapStatUpgrade`)**:
  - 雇用時および既存職員のステータス強化（勇気・慎重・自制・正義）に必要な LOB ポイントを、全ランク一律 **「1段階につき 1 LOB」** に変更します。
- **初期装備（警棒・スーツ）＆ 懺悔 E.G.O の神装備化 (`DebugStarterGearBuff`)**:
  - 警棒（ID:1）と懺悔武器（ID:200009）を ALEPH グレード（ランク補正ペナルティ無効）・射程25・超速射・威力10万〜15万に強化し、攻撃時に**相手の耐性を自動判定して吸収／無効を回避し最大ダメージが通る属性へ動的変換**するため、あらゆる敵を1撃で鎮圧可能です。
  - スーツ（ID:22）と懺悔防具（ID:300009）を全属性 0.001倍（99.9%軽減）にします。
  - ゲーム中 **`F8` キー** でいつでもバニラ数値と即座に切り替えられます。

## 🤝 BaseMod との相性・共存について

### 1. BaseMod と BepInEx の関係
- **BaseMod** はゲーム本体の `LobotomyCorp_Data/Managed/Assembly-CSharp.dll` を書き換え、古い `0Harmony.dll`（Harmony 1.2）を使用します。
- **本MOD（BepInEx版）** はゲーム本体のDLLを書き換えず、`winhttp.dll` 経由で最新の `HarmonyX`（Harmony 2.x）を読み込みます。
- フルセット版に同梱されている `BepInEx` には **`HarmonyXInterop`（旧Harmony 1.2 互換変換レイヤー）** が搭載されているため、互換処理自体は備わっていますが、環境トラブルを避けるため **クリーンなバニラ環境（BaseModなし）への導入を最も推奨** します。

### 2. BaseMod 環境からバニラ＋本MODへ移行する場合（セーブデータ保護機能）
- 本来、BaseMod で追加幻想体や追加 E.G.O MOD を導入していたセーブデータをバニラで読み込むと、存在しない装備ID・幻想体IDを参照してゲームがクラッシュします。
- 本MODには **`MissingDataGuardPatch`（欠損MODデータ自動スキップ保護機能）** が標準搭載されており、**以前 BaseMod で遊んでいたセーブデータをそのまま読み込んでもクラッシュせず安全にプレイを継続できます**。

### 3. 既存の個別MODとの重複に注意
BaseMod 等を併用する場合、以下のMODは本MODに同等・上位互換の機能が含まれているため、二重適用を防ぐために外すか `.cfg` で片方をOFFにしてください：
- `hutr2002_ChesedFix_MOD`（ケセド弾丸研究バグ修正 → 本MODの `FixChesedBulletRefiningResearch` に内蔵）
- `Pcix_Infinity_LOB_MOD` 等のLOBコスト変更系MOD（→ 本MODの `CheapStatUpgrade` と競合）

## ⌨️ ゲーム内ショートカットキー ＆ 設定ファイル

- **`F9` キー**: Lobotomy Modern Engine の稼働ステータス・FPS・メモリ使用量・各キャッシュ統計パネルを表示／非表示
- **`F8` キー**: デバッグ初期装備＆懺悔強化の即時 ON / OFF 切り替え
- **詳細設定ファイル**:
  - ゲームを1度起動すると `BepInEx/config/com.isaka.lobotonymodernengine.cfg` が生成されます（配布ZIPには最初から同梱されています）。
  - メモ帳などのテキストエディタで開き、`true` / `false` を書き換えることで全機能を1つずつ個別に ON / OFF できます。
